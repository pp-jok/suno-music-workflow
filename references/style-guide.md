# Style Prompt Guide

Write the copyable Style prompt in English, using this field order:

```text
genre and tempo or groove → vocal → instruments → arrangement arc → emotional tone → avoid items
```

Keep choices separate. **emotional tone** describes the feeling (for example, restrained, sunlit, bittersweet); **tempo, groove, hook density** describe motion and song mechanics. Do not use an emotion label as a substitute for a tempo, groove, or hook-density choice.

## Copyable prompt procedure

1. Collect only the fields the user has decided; mark undecided fields as optional rather than inventing precision.
2. Write one concise, copyable English prompt in the prescribed order.
3. Count characters before showing it. The complete prompt must stay below **1,000** characters, including avoid items.
4. If it is too long, remove repeated adjectives and low-priority detail first while preserving the chosen genre, tempo or groove, vocal, emotional tone, and avoid items.

Example structure:

```text
Mandopop, mid-tempo syncopated groove; intimate female vocal; clean electric guitar and warm synth bass; restrained verse building to a clear chorus; bittersweet but hopeful; avoid EDM drops, theatrical belting.
```
