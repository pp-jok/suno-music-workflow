# Production Plan and Style Guide

Before a Style prompt, create this card:

```text
Song identity: one recurring sonic memory
Groove: sense of pace, downbeat behavior, and hook density
Section dynamics: energy, density, vocal position, and transitions by section
Avoid items: the most likely clichés for this song
```

Choose one primary song identity: a recurring instrumental motif, rhythmic texture, vocal treatment, or transition device. It must be abstract and original, not an identifiable living artist, melody, lyric, voice, or production signature.

State how verse, pre-chorus, chorus, bridge, and final chorus change. Give the final chorus more release without automatically making it crowded.

Write the English Style prompt in this order:

```text
identity → groove → vocal → motif → instrumentation → section dynamics → emotional tone → avoid
```

Target 850–950 characters; every copyable prompt must remain below 1,000 characters. This is a workflow budget, not a claim about a permanent Suno limit.
